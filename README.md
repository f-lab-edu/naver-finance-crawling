# 네이버 뉴스 크롤러 및 데이터 분석 시스템

---

## 1. 프로젝트 개요
- **프로젝트명**: 네이버 뉴스 키워드 기반 실시간 크롤링 및 감성 분석 시스템

- **목표**:
  사용자가 요청한 키워드에 대해 네이버 뉴스에서 **실시간으로 주요 언론사의 기사를 수집**하고,
  이를 **데이터베이스에 저장 및 분석**하여 **FastAPI 기반 API**로 제공

---

## 2. 주요 기능

---

### 2.1 뉴스 수집

- 키워드 기반으로 네이버 뉴스 기사 검색
- 주요 언론사만 필터링하여 기사 수집
- `Selenium + BeautifulSoup` 기반 **비동기 스크래핑**
- **날짜 범위 지정** 기능 (기본 최근 3개월)

### 2.2 데이터 저장
- 뉴스 제목, 본문, 등록일, 언론사 정보 DB 저장
- 중복 기사 필터링 처리 (링크, 제목)
- MariaDB 저장 구조

### 2.3 감성 분석 (확장 예정)
- 감성 사전 기반 간단한 분석 -> 추후 고도화
- 분석 결과 별도 테이블로 저장

### 2.4 Streamlit UI
- 웹 기반 실시간 수집/시각화 제공
- 수집된 기사 수 및 내용 확인 (내용 확인 제공 여부는 검토 필요)

## 4. 시스템 아키텍처

---

### 4.1 기술 스택
- 백엔드: FastAPI (RESTful API 제공, 비동기 처리 - 확장 예정)
- 프론트엔드: Streamlit (웹 대시보드 구현 - 분석 데이터 시각화)
- 크롤러: Selenium + BeautifulSoup (키워드 기반 네이버 뉴스 수집)
- 데이터베이스: MariaDB (뉴스, 분석, 회원 데이터 저장)

### 4.2 시스템 구성도
```bash
┌────────────┐       ┌────────────────┐       ┌──────────────┐
│  Streamlit │ <---> │   FastAPI API  │ <---> │  MySQL DB    │
└────────────┘       └────────────────┘       └──────────────┘
   │
   └───────────>  (crawl_news.py)  --> (데이터 수집 및 저장)
                       │
                       └─────────> (text_analysis.py) --> (감성 분석 및 데이터 처리)
```

## 5. 데이터 흐름

---

### 5.1 데이터 수집
#### 1. 사용자 입력: Streamlit 대시보드에서 사용자가 키워드를 입력, 수집 기간 설정
#### 2. 크롤러 실행: 사용자가 제공한 키워드를 기반으로 네이버 뉴스에서 관련 기사들을 수집
#### 3. 기사 상세 정보 수집: 크롤링한 뉴스의 링크에서 기사 본문, 언론사, 등록일을 추가로 수집
#### 4. 데이터 저장: 수집된 뉴스 기사는 MariaDB에 저장

### 5.2 데이터 처리
#### 1. 수집된 데이터 필터링: 뉴스 제목, 본문, 언론사가 필수로 포함된 데이터만 필터링 하여 저장
#### 2. 감성 분석: 수집된 뉴스 기사를 분석하여, 감성 분석 수행 후 결과를 데이터베이스 테이블에 저장
#### 3. 데이터 제공: 분석된 데이터는 API를 통해 제공되며, Streamlit 대시보드에서 시각적으로 확인 가능

## 7. 유지보수 및 향후 계획

---

### 7.1 데이터 분석 고도화
- 시계열 분석: 뉴스 기사 수집 후 트렌드 분석 시스템 구현
- 감성 분석 고도화: 더 정교한 감성 분석 모델 도입하여 뉴스의 감성 평가 정확도 향상

### 7.2 사용자 인터페이스 확장
- 시각화: 뉴스 수집량, 분석 결과 등을 그래프 형태로 시각화 하여 분석 결과 제공
- 다양한 필터링 옵션: 날짜 범위, 언론사 선택 등의 필터링 기능 제공

### 7.3 회원 관련 기능 추가
- 회원가입 및 로그인 시스템: 
  사용자가 개별적인 수집 기록 및 분석 결과를 저장하고 관리가 가능하도록 로그인/회원가입 구현
- 맞춤형 뉴스 수집:
  사용자의 개별적인 사용자가 설정한 키워드와 기간에 따라 맞춤형 뉴스 수집을 제공, 이전 수집 결과를 기반한 
  분석 결과 제공
- 분석 이력 관리: 사용자가 이전에 수행한 분석 결과를 저장, 재분석하거나 히스트리를 확인할 수 있는 기능 제공

### 7.4 시스템 확장
- API 확장: 회원 기능에 따른 API인증 및 권한 관리 기능 (ex: OAuth 2.0, JWT 토큰 기반 인증)
- 멀티 사용자 지원: 동일 시스템을 여러 사용자가 사용 가능하도록, 다중 사용자 환경에 맞는 데이터베이스 구조와
  API 개선

### 7.5 고도화 및 자동화
- 자동화된 데이터 수집 및 분석: 크론을 사용하여 주기적으로 뉴스 기사 수집, 이를 기반으로 분석하는 자동화
시스템 구현
- 서버 성능 최적화: 데이터를 수집하고 분석하는 과정에서 발생 가능한 성능 문제를 해결하기 위한
캐싱 전략 및 데이터 파이프라인 최적화

### 7.6 보안 및 개인정보보호
- 회원 데이터 보호: 개인정보 보호를 위해 암호화 및 해시 처리 적용
- API보안: API 요청에 대한 인증 및 권한 관리
- 백업 및 복구: 수집된 데이터와 사용자 데이터를 주기적으로 백업, 데이터 유실 시 복구할 수 있는 시스템 구축
